Frequently Asked Questions

Have questions? Here are answers to common questions about setting up and using PC Remote.

Do I need internet access?

PC Remote is designed to work over your local Wi-Fi network or direct USB connection. Internet access is not required for local communication.

How does USB mode work?

USB mode uses a local USB connection between the Android device and Windows PC. The exact setup depends on the connection method supported by the application.

How do I find my pairing code?

The Windows agent displays a pairing PIN when a device is ready to connect.

Can I use PC Remote for gaming?

PC Remote can be useful for basic mouse and keyboard control, but actual responsiveness depends on the connection, device, and application.

Does my data go to the cloud?

The product is designed around local communication. Direct control messages flow between your phone and PC over your local network.

What operating systems are supported?

Windows 7 / 8 / 10 / 11 for the desktop agent, and Android 8.0+ for the controller app.
